# Leave Application

An **Academic Calendar & Leave Management System** developed using **ASP.NET Web Forms and C#** as part of the .NET Technologies practical.

## 📌 Experiment

**Experiment 5 – Leave Applications**

**Subject:** .NET Technologies  
**Course:** B.Tech Computer Science and Engineering

## 📖 Description

This project is a web-based leave management application that allows students or faculty members to submit leave or academic event details.

The application provides a simple interface to:

- Enter student/faculty name
- Select a date using an academic calendar
- Select an event type
- Enter a leave reason or description
- Validate the submitted information
- Display the submitted details
- Store user information using Session
- Remember the user's name using Cookies

## ✨ Features

- Academic Calendar
- Leave Application Form
- Academic Event / Leave selection
- Form validation
- Session management
- Cookie management
- Submitted details display
- Simple responsive-style user interface
